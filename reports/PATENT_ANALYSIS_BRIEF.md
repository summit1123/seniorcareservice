## 1. 발명 개요 (한 문단)

고령 운전자의 텔레매틱스 방문 이벤트로부터 **개인별 생활권(life zone)을 지역
유형에 따라 군집 기준거리를 달리하는 밀도 군집화로 자동 학습**하고, 위치
자체(생활권 밖 주행)에는 판정 점수를 부여하지 않는 **위치 중립 원칙** 하에,
개인의 직전 이력 대비 **이동 패턴과 위험운전 행동이 같은 평가월에 동시
급변**했을 때만 **비할증 케어 상태**(기본보험료 초과 할증 없이 우대 보너스
정지 + 사람 검토 + 예방적 개입)를 여는 자동차보험 판정 시스템. 케어 상태는
학습된 기준선 대비 이탈 지속 조건이 깨지는 평가월에 자동 해제된다. 연간
보험료 우대(safe-driving reward)와 월 단위 케어 개입은 **독립된 2축**으로
운영된다.

한 줄 요약: *"지오펜스 이탈을 벌하는 보험"의 반대 — 이탈은 점수에 산입되지
않고, '평소 대비 동시 급변'만이 비할증 개입 신호다.*

## 2. 배경 / 해결하려는 문제

- 기존 UBI(usage-based insurance)는 급제동·과속 등 **행동 이벤트의 절대량**을
  점수화 → 저주행 고령자는 데이터가 적고, 지역 환경(도심/농촌) 차이로 불공정.
- 기존 마일리지 특약은 **주행거리만** 반영 → 고령 저주행자의 위험 신호(패턴
  급변)를 포착하지 못하고, 사고 심도가 높은 세그먼트의 protection gap 방치.
- 기존 지오펜싱 기반 접근(치매 배회 감지, 존 이탈 알림)은 **이탈 자체를
  이벤트/페널티로 취급** → 이동권 위축, 낙인 효과, 보험 인수 맥락에서는 위치
  차별 문제.
- 고령자의 이동·행동 패턴 급변은 신체·인지 변화의 조기 신호로 보고됨 → 사고
  "원인" 판정이 아니라 **사람이 점검할 시점을 알리는 개입 트리거**로 쓰는 것이
  본 발명의 입장.

## 3. 기술 구성 (구성요소별 — 구현 대조 검증됨)

### C1. 지역 적응형 생활권 학습부
- 입력: 트립당 1개의 **도착지 점 좌표**(위·경도)와 방문 시각, 트립 거리, 위험
  이벤트 수. **경로 궤적(폴리라인)은 수집·사용하지 않음.** 생활권 존은 점
  좌표로부터 유도되는 산출물이다.
- DBSCAN 계열 밀도 군집화로 반복 방문 군집을 학습. **군집 기준거리(eps)를
  지역 유형별로 차등**: 고밀도 도심 260 m / 교외 중밀도 520 m / 광역 저밀도
  1,100 m. 현 구현에서 지역 유형은 외부 입력(운영 시 행정구역·밀도 통계 매핑
  가능한 선언적 파라미터)이며, eps는 유형별 파라미터로 교체 가능(지역 어댑터).
- 학습 결과: **자택 중심 생활권 존 1개(자택 인근 목적지 병합) + 조건 충족 시
  보조 생활권 존 최대 1개**(제2 생활거점 — 예: 가족 집). 판정은 존 대비
  core/buffer/outer 구분으로 수행.
- 가입 초기 2개월 = 생활권 학습 기간(판정 제외, 기준선 산출에 사용).

### C2. 위치 중립 판정 원칙 (선언적 규칙)
- `outer_zone_policy: context_only_no_location_penalty` — 생활권 밖 방문
  이벤트는 **판정 점수에 산입되지 않고 맥락 변수로만 처리**된다(긍정 한정).
  원거리·광역 이동 자체는 감점·할증 사유가 아님.
- 효과: 지오펜스 이탈 페널티 구조와의 명시적 차별화, 이동권 보존.

### C3. 2단계 케어 트리거 (핵심 판정 로직 — 상태기계)

사용 지표 (평가월 단위):
- **이동 지표** = 생활권 밖 방문 비중 (0~1)
- **위험행동 지표** = 위험 트립 비율 = 위험 이벤트가 1건 이상 발생한 트립 수 /
  전체 트립 수 (0~1). ※ 100km당 이벤트율이 아님 — 그 지표는 우대 축 안전
  점수(C5)에만 사용.

기준선은 **두 종류**를 사용한다:
- **감지용(trailing)**: 직전 2개월 이동평균
- **유지·해제 및 노출 지수용(고정)**: 가입 초기 2개월 학습 기준선

상태 전이표:

| 전이 | 조건 |
|---|---|
| 정상 → 케어 (개시) | (이번 달 이동 지표 − 직전 2개월 평균) ≥ 25%p **AND** (이번 달 위험행동 지표 − 직전 2개월 평균) ≥ 20%p — 동일 평가월 동시 초과 |
| 케어 → 케어 (유지) | 학습 기준선 대비 이동 이탈 ≥ 25%p **AND** 위험행동 이탈 ≥ 20%p 모두 지속 |
| 케어 → 정상 (해제) | 위 유지 조건 중 **어느 하나라도** 임계 미만이 된 평가월 — 그 달부터 정상(같은 달 해제) |

- 경계 사례(구현 검증): 한 축만 급변(예: 이사로 이동만 변화)하면 미발동 —
  오탐 방어 내장. 영구 이주(이동 이탈 지속 + 위험행동 정상화)는 위험행동 축
  미충족으로 해제됨(180 시나리오 중 해제 2건 모두 이 패턴). 신규 생활권
  재학습은 담당자 승인 절차로 로드맵화. 데이터 미달 월의 케어 축 처리 규칙은
  명세화 시 확정 필요(우대 축은 '보류' 처리 구현됨).
- 케어 상태의 효과(구현 기준): 기본보험료를 초과하는 **할증은 없음**(할인율
  하한 0%). **월 효과** = 해당 월은 우대 충족 월로 산입되지 않음. **연 효과** =
  연간 케어 검토 상태이면 우대 보너스 미적용 + 마일리지 기준 할인율에서
  13%p 차감 → 기준상품 대비 최종 보험료가 높아질 수 있음(할인 축소 방식,
  discount-leakage 방지 명목). + 담당자 검토 큐 생성 + 예방적 지원(검진 연계,
  상담, 가족 알림은 옵트인).

### C4. 독립 2축 상품 구조
- **우대 축(연간)**: 4지표 가중합(주행 30 / 생활권 내 안전 30 / 생활권 밖 안전
  20 / 패턴 안정성 20) ≥ 임계(75점)를 12개월 중 9개월 충족 시 보험료 우대
  (최대 7%p). 데이터 미달 월은 '보류'(불이익 없음).
- **케어 축(월)**: C3. 두 축은 독립 — "연간 우대 + 케어 월 존재"가 공존 가능.
- 요율 산식·임계가 전부 선언적 파라미터(product rules)로 외부화되어 있어,
  규제 검토·심사 시 실시간 재계산 시연 가능(rate sandbox).

### C5. 비율 기반 채점 (지역 공정성)
- 우대 축 안전 점수는 이벤트 절대 수가 아니라 **100km당 비율 지수** → 도심
  1km와 농촌 1km의 위험 밀도 차이 왜곡 완화.
- 실측(180 시나리오, 동일인 × 3환경): **연간 케어 판정은 60/60명 환경 간
  동일. 연간 우대 판정은 56/60명 동일** — 갈리는 4명은 전원 케어 발동자로,
  케어로 정지된 월수가 환경별로 달라 우대 충족 월수가 갈린 경우다. 월 단위
  우대 충족은 21/60명이 환경 간 1개월 이상 갈림.

### C6. 프라이버시 보존 구조 (데이터 최소화)
- **궤적(폴리라인) 비수집** — 트립당 도착지 점 좌표 1개만 수집하며, 존
  판정·군집화는 그 점 좌표 위에서 수행된다(완전한 '좌표 비수집'은 아님 —
  과장 금지).
- 표시·리포트 계층으로는 좌표가 나가지 않는 allowlist sanitizer — UI 지도는
  자택 기준 상대변위(10m 반올림)만 사용.
- 가족 알림은 디폴트 OFF(옵트인 신청).

### C7. 공공 사고통계 앵커 (위험 유형 가중)
- 위험운전 이벤트의 유형 분해 가중치(급제동/과속/급가속/야간)를 공공 사고통계
  (도로교통공단 TAAS 2010–2024)에서 **코드가 직접 산출** — 원천 CSV → 산출
  코드 → 엔진 가중치의 검증 가능한 사슬. (유형 분해는 설명·리포트용이며 판정
  점수에는 불개입.)

### C8. 설명가능성 계층 (보조 구성)
- 판정마다 XAI 사유(어떤 지수가 언제 임계를 넘었는지) + 위험 유형 칩 노출.
- LLM 기반 케어 리포트: 결정론 엔진의 확정 수치만 인용하도록 구조화 출력 +
  스키마 검증(수치 재계산·발명 금지 가드), 실패 시 결정론 서사 폴백.

### C9. 합성 검증 파이프라인 (방법론 — 별건 검토 가치)
- LLM이 페르소나별 생활권 프로필(장소·방향·비중·변화 시점)을 생성하고, 구조
  계약을 코드가 검증·재시도 → 결정론 엔진이 **유형 라벨을 모른 채** 군집·채점
  (블라인드 채점) → 유형별 기대 판정 계약 테스트로 상품 로직의 일관성만 검증
  (예측력 주장 없음). 시드 고정으로 비트 단위 재현.

## 4. 신규성 후보 (조사 대상) — 기존 기술 대비 차별점

**★ 1순위 훅 (조사를 조직할 최소 구별 조합)** — N1:
"개인 트레일링 기준선 대비 **이동·위험행동 2지수의 동일 평가월 동시(AND)
초과**를 유일한 개시 트리거로 하고, **위치 이탈 자체는 점수에 산입하지
않으며**, 개시된 상태는 학습 기준선 대비 지속 조건이 깨지는 즉시 **자동
해제**되고, 상태의 효과가 할증이 아니라 **보너스 정지 + 사람 개입**인 보험
판정 상태기계." 이 조합의 선행 존재 여부가 조사의 핵심 질문이다.

| # | 차별점 후보 | 가장 가까울 것으로 예상되는 선행 영역 |
|---|---|---|
| N1 | ★위 1순위 훅 조합 | 지오펜스 이탈 알림(치매 배회 감지 — G08B 21/02 계열), UBI 이상운전 감지, digital phenotyping 행동 변화 감지 — 대부분 단일 축·이탈 자체를 이벤트화 |
| N2 | 감지=트레일링 / 유지·해제=고정 학습 기준선의 **이원 기준선 2단계 상태기계**(같은 달 자동 해제) | 변화점 탐지(CUSUM 등) 일반, AAL routine-deviation 감지 — 보험 개입 상태기계와 결합 사례 조사 필요 |
| N3 | **지역 유형별 eps 차등 생활권 군집화**를 보험 요율 판정에 결합 | 궤적 군집화 특허·학술 + **OPTICS/HDBSCAN/VDBSCAN 등 밀도 자동 적응 군집화**(수동 3단 차등이 이들의 좁은 특수 사례로 읽힐 위험 — 진보성 공격 1순위 예상) |
| N4 | **비할증 개입 설계**: 케어 = 보너스 정지(+할인 축소) + 사람 검토 + 예방 지원, 우대 축과 독립 2축 | 웰니스 연계 보험(Vitality류), Sompo 치매 케어 보험, care management — 자동차보험 요율 구조와의 결합 형태 조사 |
| N5 | 궤적 비수집(도착지 점만) + 좌표 비노출 표시 계층의 **데이터 최소화 텔레매틱스 요율** | 프라이버시 보존 UBI(암호화·엣지 집계) — 접근이 다름(수집 단계 최소화 + 표시 차단) |
| N6 | 공공 사고통계에서 위험 유형 가중치를 직접 유도하는 검증 가능 파이프라인 | 요율 산출 일반 — 단독 청구는 약함, 종속항 후보 |

주의(정직 고지): N1~N3의 개별 요소(지오펜싱, 변화점 탐지, DBSCAN, UBI 점수화)는
각각 공지 기술이다. 청구 가능성은 조합에 있고, 조합의 정의는 위 1순위 훅
문장을 기준으로 한다. (2축 독립 운영은 종속항 후보로 내림 — 독립항 조합에는
불포함.)

## 5. 청구항 초안 스케치 (조사 범위 설정용 — 법률 자문 아님)

- **방법항(안)**: (a) 차량 텔레매틱스로부터 트립당 도착지 좌표를 포함하는 방문
  이벤트를 수집하는 단계; (b) 지역 유형에 따라 군집 기준거리를 달리하는 밀도
  군집화로 운전자별 생활권 존(자택 존 및 보조 존)을 학습하는 단계; (c) 평가
  월의 생활권 밖 이동 비중 및 위험운전 트립 비율을 각각 직전 N개월 이동평균과
  비교하여 이동변화량·행동변화량을 산출하는 단계; (d) 두 변화량이 각 임계를
  동일 평가월에 동시 초과하는 경우에만 케어 상태를 개시하는 단계; (e) 개시 후
  학습 기준선 대비 두 이탈 지수가 모두 임계 이상인 동안 케어 상태를 유지하고,
  어느 하나가 임계 미만이 된 평가월에 자동 해제하는 단계; (f) 케어 상태에서
  기본보험료를 초과하는 할증 없이 우대 보너스 적용을 정지하고 사람 검토 개입
  신호를 생성하는 단계; 를 포함하고, (g) 생활권 외 방문 이벤트를 판정 점수에
  산입하지 않고 맥락 변수로만 처리하는 것을 특징으로 하는 방법.
  ※ 구현 변형: (f)에서 연간 케어 검토 시 할인율 일부 차감(13%p, 하한 0)을
  병용 — 종속항 또는 설계 선택지로 기재.
- **시스템항(안)**: 수집부 / 지역 적응 생활권 학습부 / 이원 기준선 변화
  감지부 / 위치 중립 판정부 / 개입 관리부 / 프라이버시 필터부(도착지 점 좌표
  한정 수집·표시 계층 좌표 비노출)를 포함하는 시스템.
- 종속항 후보: 환경별 eps 값 차등과 지역 어댑터, 보류(미달 월) 처리, 2축 독립
  운영, 케어 연도 할인 차감, 공공통계 유도 유형 가중, XAI 사유 생성, 옵트인
  가족 알림, 보조 생활권(제2 거점) 인정.
