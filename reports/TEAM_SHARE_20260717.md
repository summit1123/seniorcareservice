# 팀 공유 — 대시보드·덱 현황과 피드백 요청 (2026-07-17)

브랜치: `claude/gaip-dashboard-refine` · 데모: foursure.summit1123.co.kr (배포 진행 중)
검증 상태: typecheck 0 · JS 테스트 22 · pytest 250(계약 전부 통과) · 데이터 전수 스캔 완료

## 최근 반영 (이번 주)

1. **케어 리포트 전면 개편** — 생성 진행 화면(절제된 모션) → 응답 확정 시 리포트 전체 일괄 등장.
   리포트 번호·관찰 기간·커버리지 마스트헤드 + 01~06 섹션. AI가 쓴 곳 전부 'AI 생성' 배지.
   **02 종합 소견**: AI가 "이번 달 운전 → 우려 지점 → 우대/케어 축 판단 → 권고와 다음 달" 볼드
   리드인 구조로 심사역 소견을 씀(수치는 전부 엔진 확정값, AI는 서사만).
2. **가족 앱(MASIL Family)** — 직원 승인 → 자녀 앱 전달 흐름. 상태바·하단 탭바·드래그 스크롤,
   비징벌 언어, '부모님 대신 신청하기'.
3. **생활권 지도 실측화** — 지도의 모든 점 = 엔진이 생성한 실제 방문(자택 기준 상대변위, 절대좌표는
   sanitizer가 차단). 기준선 2개월 회색 고스트 vs 선택 월 주황 위험 점으로 "어떻게 달라졌는지"가 보임.
4. **요율 비교 명확화** — 연간 할인율·연 보험료 명시 + 이득/부담 판정 라인(케어 달 보너스 정지 설명).
5. **실험실 가독화** — HDBSCAN 칩 '무리 3 · 이웃 2' + 평문 설명, 과병합·누락 'N명/60' 인원 표기.
6. **기타** — 사례 카드 2축 뱃지(연간 우대/기본 + 케어 검토 월), 스트림 리포트 언어 연동(5개어),
   모바일 반응형, 타임라인 선택 월까지만 표시.

## 피드백 요청 (이거만 봐주세요)

1. **첫인상**: 판정 화면에서 "연간 우대 + 케어 검토 월" 뱃지가 설명 없이 이해되나요?
2. **종합 소견 톤**: 케어 리포트 02가 실제 심사역이 쓸 법한 문장인가요? 과하거나 빠진 것?
3. **가족 앱 문구**: 부모님 걱정하는 자녀 입장에서 이 메시지를 받으면 어떤 기분일까요?
   (불안 유발 vs 안심) 특히 "한 번 살펴봐 주세요" 헤드라인.
4. **덱 아크**: 스토리라인 12장 중 빼야 할 장 / 순서 바꿀 장?
5. **데모 리허설**: 2분 스크립트로 각자 한 번 돌려보고 막히는 지점 공유.
