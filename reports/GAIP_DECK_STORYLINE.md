# GAIP 2026 덱 스토리라인 — MASIL (FourSure)

> 마감 2026-08-07 · 발표 영어 · 데모는 대시보드 라이브(영어 기본 화면)
> 뼈대: **문제 → 제품 논리(2축) → 눈으로 확인(데모) → 신뢰 구조 → 경제성 → 이식성 → 파일럿**
> 원칙: 약점(합성 데이터·illustrative 요율)은 숨기지 않고 슬라이드로 정면 돌파한다.

## 슬라이드 아크 (12장)

**S1. Cold open — 한 사람의 12월** (30초)
- 윤순예(68), 도심 저주행. 11개월 안전 → 12월, 낯선 야간 경로 + 급제동 동시 급증.
- "오늘날의 보험은 이 순간에 두 가지 중 하나를 합니다: 아무것도 안 하거나, 요율을 올리거나."
- 훅: *"우리는 세 번째를 만들었습니다 — 그 달만 사람이 들여다보고, 검진을 보냅니다."*

**S2. Protection gap — 숫자로**
- 시니어 저주행층: 연 3~5천km인데 요율은 연령 할증. 보험료-위험 불일치(과납) + 갱신 이탈.
- 고령 사고의 높은 심도(치사율) — 빈도가 아니라 **변화 감지**가 레버라는 근거.
- (인용 확정: TAAS 연령대별 치사율, 시니어 주행거리 분포)

**S3. 두 가지 미충족 니즈 = GAIP 브리프 매핑**
- ① Protection gap: 정확한 가격 (마일리지+생활권 기반 우대)
- ② Behavioral/human: 사고 전 개입 (케어 축 + 가족 연결)
- 한 문장: *"Price precisely. Intervene humanely."*

**S4. 제품 논리 — 2축, 3등급이 아니라**
- 우대 축(연간, 보험료 질문) ⊥ 케어 축(월, 개입 질문). 동시변화 게이트(이동≥25%p AND 위험≥20%p).
- 케어 달엔 벌점이 아니라 **보너스만 일시정지 + 예방 연결** — 낙인 없는 개입.
- 다이어그램 1장: 두 축 매트릭스 위에 6개 페르소나 배치.

**S5. 신뢰 구조 — "감사 가능한 AI"** (심사위원 저격 슬라이드)
- 숫자는 결정론 엔진, AI는 서사만(구조적 분리·재계산 금지) / XAI 사유 / 선언된 임계값.
- 프라이버시 경계: allowlist sanitizer — 원시 GPS는 UI로 못 나감, 지도는 자택 기준 상대변위.
- 알고리즘 실험실: 같은 60명 통제 비교, 과병합 0명/60 — 파라미터 선택의 근거를 공개.

**S6~7. 라이브 데모** (아래 2분 스크립트)

**S8. 케어 리포트 — human-in-the-loop 운영 흐름**
- 생성(AI 서사+엔진 수치) → 직원 검수(승인/보류/메모) → 가족 앱 전달(동의 계약만).
- 스크린샷 3장: 생성 화면 / 종합 소견 / MASIL Family.

**S9. 경제성 — 반사실 손익** (`reports/loss_ratio_counterfactual.md`)
- Giveaway 연 −1.74% vs 케어 세그먼트(16.7%) 클레임 **breakeven 10~12% 절감**.
- 문헌 보고 범위(20~40% 위험행동 감소)의 절반 이하 = 보수적으로도 흑자 방향.
- 화법: *"할인을 더 주는 게 아니라 정확히 주고, 남는 돈으로 사고를 미리 삽니다."*

**S10. 이식성 — 지역 어댑터**
- 밀도별 eps 하나만 재보정(도심 260m/교외 520m/광역 1100m 실측) → 싱가포르 밀도 적용 시나리오.
- "모델을 새로 만들 필요가 없습니다 — 기준 거리만 그 도시에 맞춥니다."

**S11. 정직한 한계 + 파일럿 설계** (약점 정면 돌파)
- 지금까지는 합성 180 시나리오(공개 통계 앵커) — 그래서 다음 단계가 파일럿.
- 6개월 파일럿 설계: 시니어 옵트인 → 케어 개입군/대조군 → 클레임·이탈률 측정. KPI 3개.

**S12. 팀 + Ask**
- 요청: 파일럿 파트너(보험사·검진기관) + 규제 샌드박스.

## 예상 Q&A (상위 6)

1. **실데이터는?** → S11 그대로: 합성은 설계 검증용, 앵커는 공개 통계, 파일럿 설계가 답.
2. **어차피 할인 더 주는 것 아닌가?** → S9 breakeven 수치 + "정확히 주는 상품".
3. **케어가 낙인 아닌가?** → 벌점·감액 없음(보너스 일시정지만), 가족 동의 기반, 비징벌 언어 설계.
4. **프라이버시?** → allowlist sanitizer 코드 레벨 시연 가능, 좌표 비노출, XAI로 반박 가능성 보장.
5. **왜 임계 25/20%p인가?** → 요율 샌드박스 라이브로 민감도 시연(임계 바꾸면 판정 재계산).
6. **싱가포르에서 되나?** → S10 어댑터 + 도시국가는 오히려 밀도 파라미터 1개로 충분.
