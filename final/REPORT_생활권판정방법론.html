2026-07-24 · 모든 수치는 코드·데이터 실측, 모든 인용은 원문 확인 · 심사 질문 대응 순서로 구성 (1장 어떻게 만드나 → 2장 숫자 근거 → 3장 고객 영향 → 4장 검증 → 5장 한계)

1생활권의 정의와 생성 원리

1-1. 입력 데이터 — 시동 기반 방문 이벤트

트립당 1개, 시동을 끈 지점의 점 좌표 + 날짜만 사용한다. 주행 궤적(폴리라인)은 수집하지 않는다 — 이유는 둘:

  • 프라이버시: 데이터 최소화. 표시 계층은 좌표 자체를 차단(자택 기준 상대변위 10m 반올림).
  • 방법론: 원시 GPS 스트림을 군집화에 넣으면 이동 한 번에도 도로를 따라 수백 점이 찍혀 도로가 생활권으로 오인된다. 정류점(시동 끔) 단위가 올바른 입력.

1-2. 생성 3단계

시동 끈 점들 → [① 묶기] 서로 260m 안이면 같은 덩어리로 연쇄 (eps — 지역별 260/520/1,100m) → [② 승격] 덩어리 안 점들의 서로 다른 날짜 ≥ 3일이면 생활 거점 (하루 중복 = 1일) → [③ 원] 확정 거점에 상품 존: 중심권 500m(보장) + 완충 P90(실측, 하한 500m·상한 2km) 이후 매달: 고정된 원에 비춰 방문을 안/밖으로 집계 (원은 재학습 절차 전까지 불변)
  • eps는 "이웃으로 볼 반경"이지 생활권 반경이 아니다 — 묶기가 끝나면 역할 종료, 화면에 그려지지 않는다.
  • 연쇄의 용도는 거점 내부: 시장 입구·골목·주차장의 산포를 한 거점으로 뭉치는 접착제. 집·시장·복지관은 이어지지 않고 각자 섬이 되는 게 정상 — 생활권은 군도(섬들의 집합)다.
  • 날짜로 세는 이유: 점 개수 기준이면 하루 중복 방문(주차 이동·중복 핑)이 습관으로 둔갑한다. 부수 효과로 일회성 경유지가 두 동네를 잇는 다리가 되는 것도 차단.

탈락 = 삭제가 아니다. 전부 "생활권 밖 방문"으로 남아 월별 밖 비중(변화 감지 재료)이 된다. 노이즈에 별도 필터는 없다 — 합격 규칙의 여집합이 자동으로 노이즈다.

2-2. "왜 3일" — 4겹

  • 문헌 정면 일치: Isaacman et al. 2011 (Pervasive) — 중요 장소 기준 = "관찰 일수의 5% 초과 = 60일 데이터에서 서로 다른 날 3일 이상" + 통화 수 아닌 접촉 일수(call-days)로 계수. 관찰 창·단위·값 모두 우리와 일치. 원문 PDF
  • 오류 확률(푸아송): 임계 2일 = 우연 방문지(2개월 1회, λ=1) 오인 26.4% / 3일 = 8.0% / 4일 = 1.9%이지만 월 2회급 진짜 거점(λ=4) 성립률이 56.7%로 급락 → 3 = 오인·누락 동시 억제 최소 정수
  • 빈도 앵커(국내 공식 통계): 65세+ 월평균 입내원 3.75일(건보공단 2022) → 병원 성립률 98.0% · 경로당 이용자 주 2.9회 · 복지관 이용자 주 1.5회(2023 노인실태조사)
  • 비용 비대칭 설계: 우연 장소 포함 실수는 저비용(위치 중립·기준선일 뿐), 진짜 거점 누락은 고비용(밖 비중 상시 오염) → 문턱은 우연만 거를 만큼 낮게

2-3. "왜 2개월" — 3겹

  • 역산: 고령운전자 최빈 운전 빈도 주 3~5회(소비자원 2024) → 2개월 26~43회 운전 → 월 2회급 저빈도 거점도 3일 임계 안정 충족. 1개월은 경계.
  • 선례 스펙트럼: UMTRI 2주 → DRIVES 1개월 → Isaacman 60일(우리와 동일) → DHQ 3개월 → Candrive 4개월 → 업계 rating 3~6개월. "연구 기준선보다 보수적, 업계 관행보다 신속한 중간값."
  • 민감도 실측(예정): 1/2/3개월 재판정 비교 — 엔진 파라미터라 즉시 가능.
⚠ Lally(습관 66일)는 보조 한 문장으로만 — 새 습관 형성 연구이지 기존 패턴 관측 기간 근거가 아니며, 범위가 18~254일이라 주력으로 쓰면 역공당함.

2-4. "왜 260/520/1,100" — 정직한 3겹

  • 인정: 절대값을 주는 문헌은 없다 — 설계값이다.
  • 기준값은 문헌 대역: 장소인식 연구의 공간 임계 — Zheng 200m, Montoliu 권장 200~300m → 도심 260m는 그 한가운데.
  • 나머지는 축척 규칙: 260→520→1,100은 ×2 비례 — 환경 설계 전체(트립 5.4/11/24km, 도달반경 900/1,500/3,000m)와 같은 축척. 임의 숫자 3개가 아니라 "기준값 1 + 규칙 1".
  • 확정은 파일럿: 실데이터의 지역별 k-거리 그래프로 재도출(원논문 표준 휴리스틱).

2-5. 중심권 500m와 P90 — 약속과 측정

P90 = "당신은 실제로 이만큼 다닙니다"(측정) · 500m = "그래도 최소 이만큼은 인정합니다"(약속)
  • 하한이 없으면: 규칙적인 고객의 P90이 150m로 나와, 길 건너 주차(200m)가 "생활권 밖"으로 찍히는 잔진동 오염 발생 → 고객에게 불리한 방향으로는 측정을 따라가지 않는다는 보호 하한.
  • 2km 상한 = 역방향 보호(원이 무한 확장되면 감지 신호 자체가 죽음).
  • P90에 최댓값·평균을 안 쓰는 이유: 장날 한 번의 900m 주차가 원을 4배로 키우는 것 방지.

3판정 로직과 요율 연결

3-1. 안/밖은 벌점이 아니라 눈금

  • 원 밖 방문 = 집계만 됨. 위치는 점수에 산입되지 않는다(outer_zone_policy: context_only_no_location_penalty).
  • 위험운전은 장소 불문 동일 무게 — 케어 축 위험 지표(위험 트립 비율)는 위치를 안 본다. 우대 점수는 오히려 권내 안전(30) > 권외 안전(20) — 삶의 대부분이 안에서 일어나므로.
  • 밖이 의미를 갖는 유일한 순간: "밖 비중 급증"과 "위험행동 급증"이 같은 달에 동시일 때 — 밖의 위험 가중이 아니라 변화의 동시성.
어디서어떻게결과
김생활권 안에서만급제동 잦음(만성)안전점수 하락 → 기본. 케어 아님(변화 아님) — 이 유형 30건 실측
박매달 멀리안전우대 유지 — 밖 비중 높아도 무관(광역·복수생활권형 실측)
이평소 안 → 이번 달 밖 급증위험행동도 동반 급증케어 — 밖이라서가 아니라 평소와 달라져서

3-2. 돈에 생기는 일 — 정직 버전

  • 할증은 구조상 부재: 할증률 0 고정 + 할인 하한 0% → 기본보험료 초과 불가.
  • 위치 전면 변경(이사)만으로는 아무 일도 없음 — 이사형 30건 전원 케어 미발동·우대 유지.
  • 케어(동시 급변) 시: 그 달 우대 미산입, 연간 케어면 보너스 정지 + 할인 13%p 축소 → 마일리지 기준상품 대비 순보험료가 높아질 수 있음(정직 고지 필수 — "불이익 전혀 없음" 발화 금지).
  • 해제: 학습 기준선 대비 두 이탈 지수 중 하나라도 임계 미만이 된 평가월에 자동 해제(같은 달). "복귀해야 해제" 아님 — 영구 이주도 운전이 안정되면 해제.

4검증 체계 — 알고리즘 실험실

4-1. 지표 읽는 법

지표뜻이 수치가 증명하는 것
커버리지방문점 중 어느 거점에든 소속된 비율(~90%대)방문 대부분이 생활권으로 설명됨
소음어디에도 못 붙은 일회성 방문(6~7%)0%가 아닌 게 정상 — 일회성까지 묶지 않았다는 뜻
과병합다른 목적지가 한 덩어리로 합쳐진 사람 수 — 0/60eps가 과대하지 않음 (원논문 자인 사고의 실측 부재)
정기거점 누락진짜 거점이 성립 못 한 사람 수 — 1~2/60eps가 과소하지도 않음 (파편화 거의 없음)

채점이 가능한 이유: 합성 데이터에는 정답 라벨(어느 방문이 설계상 어느 존인지)이 있다 — "합성 = 로직 검증용" 주장의 실물. 화면 하단에 Simulated 명시 + "알고리즘 채택·교체는 사람 검토로 결정" 거버넌스 문장 포함.

4-2. 판정 강건성 실측

  • 같은 사람 × 3환경: 연간 케어 판정 60/60 동일 · 연간 우대 56/60 동일(갈림 4명은 전원 케어 발동자 — 케어 정지 월수 차이).
  • HDBSCAN 비교 실측: 대표 사례(gaip-091)에서 무리3·이웃2 설정 시 거점 8개로 파편화, 커버리지 71.9%로 하락 — "왜 기본으로 안 쓰나"의 실측 증거. eps 제거의 대가는 파라미터가 미터(설명 가능)에서 개수·안정성(설명 곤란)으로 이동하는 것.

5한계와 로드맵 (선제 선언)

  • 미확인 통계: 국내 고령 운전자 연령별 연 주행거리 — 공개 웹에 부재. 보험개발원 접근 또는 일본 JAMA(65세+ 연 ~3,500km)·미국 FHWA(전연령의 57%) 비율 앵커 명시 사용.
  • eps 파일럿 보정: 지역별 k-거리 그래프로 데이터에서 재도출(원논문 표준 방법).
  • 실데이터 3단 파이프라인(로드맵): 엣지 정류점 추출 → HDBSCAN → 방문일수 필터 — 문헌 표준 구조. 현 구현(시동점 + 지역별 eps + 3일 내장)은 설명가능성·프라이버시·소표본에 최적화된 현 단계 선택.
  • 재학습 절차: 이사 후 신규 생활권 반영은 담당자 승인 게이트(자동 아님).
