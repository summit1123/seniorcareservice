# 팀 조사(HDBSCAN·DEGURBA 스코어링) 삼분류 + 결정안

> 은서 조사 문서(정류점→HDBSCAN→일수필터→P90 파이프라인 + DEGURBA 밖 주행
> 스코어링 + 밀도 보정 계열 리서치)에 대한 평가. 결론: **버릴 것 거의 없음 —
> 70%는 우리 근거를 보강하는 재료, 결정 필요한 건 2개.** (2026-07-28)

## ② 조건부 채택 — 3곳 고쳐서 넣을 것 【결정 ②】

**DEGURBA 밖 주행 스코어링 수식** (w=빈도율 × sev=치사율 × 거리, 분모 직교 설계
자체는 우수):

1. 절대 임계(`r ≥ θ → Care`) ❌ → **직전 2개월 평균 대비 Δr 급변**으로 전환.
   절대 임계 = 위치 벌점 → 심사 A-1 방어선("교란 요인은 판정 불진입")과 지역
   공정성(케어 60/60) 붕괴. Δ변화형이면 위치 중립(개인 기준선 대비) 유지하며
   w·sev 작업 전부 수용 가능.
2. "지나간 지역" ❌ → **도착지 티어**로. 경로(폴리라인) 미수집 — 데이터 추가
   없이 가능.
3. **행동 축(위험운전) 보존** — 이 수식엔 행동이 없음. 단독으로 케어를 자르면
   안 되고, 케어 **이동 축의 정교화**로만 (AND 게이트 유지).

→ 은서의 w·sev TAAS 캘리브레이션 작업(조회 경로 포함)은 **그대로 진행(Go)** —
쓰이는 자리만 바뀜.

## ③ 기각 — 단, 조사자가 몰랐던 실측 때문 【결정 ①】

**"HDBSCAN을 개인 생활권 생성의 메인으로"** — 기각, 현행(지역별 eps + 3일) 유지.

- 은서 분석에 **누락된 입력**: 실험실 실측 — 같은 데이터에서 HDBSCAN이 생활권을
  **8조각**으로 파편화, 커버리지 **90%대 → 71.9%**. (메커니즘: 거점 하나 안의
  우연한 주차 몰림을 소표본에서 "서로 다른 군집"으로 오독)
- 은서가 말한 HDBSCAN의 XAI 장점("min_cluster_size = '몇 번 방문' 의미로
  해석")은 **우리 3일 조건이 이미 보유** — "서로 다른 3일 방문 = 생활 거점"이
  같은 해석이고, 은서가 찾은 일수 문헌이 정확히 이를 지지.
- HDBSCAN의 자리: 실험실 비교 유지 + **실데이터 파일럿(사람당 점 수백 개~)
  승격 후보**. "쓰냐 마냐"가 아니라 "언제 쓰냐" — 갈아타는 조건까지 정의됨.

## 은서에게 전달 (채팅용)

> 조사 거의 다 채택 — 일수 문헌 2건과 엔트로피 논문은 근거 노트에 바로 들어감
> (3일 규칙·지역별 eps의 국제 앵커). 두 가지만 조정: ① HDBSCAN 메인 채택은
> 우리 실험실 실측(같은 데이터에서 커버리지 90→72%, 거점 8조각)이 반대라 현행
> 유지 + 파일럿 승격 후보로. 네가 말한 min_cluster_size의 XAI 장점('몇 번
> 방문')은 우리 3일 조건이 이미 같은 해석이고 네가 찾은 일수 문헌이 그걸 지지함.
> ② 스코어링 수식은 절대 임계 대신 '평소 대비 Δr'로 넣자 — 절대 임계는 위치
> 벌점이라 심사 1번 지적(위치 중립 답변)과 충돌. w·sev TAAS 캘리브레이션은
> 그대로 고(Go).
