### 수정한 것

1. **"HDBSCAN 커버리지 90%→71.9%, 거점 8조각"** — 세 문서(구 README 3-1, 팀조사
   문서, 방법론 리포트)에 실려 있던 이 서술은 **인과가 잘못 붙어 있었다.**
   71.9%의 출처는 대표 사례 `gaip-091` 한 명이고, 현재 스냅샷에서 이 사람의
   커버리지는 **어느 설정에서도 71.9%로 동일**하다:

   | gaip-091 | 거점 수 | 커버리지 | 노이즈 |
   |---|---:|---:|---:|
   | DBSCAN eps260 + 3일 | 2 | **71.9%** | 0.0% |
   | HDBSCAN 3/2 | 8 | **71.9%** | 4.8% |
   | HDBSCAN 5/3 | 2 | **71.9%** | 0.0% |

   즉 거점 파편화는 사실이지만 **커버리지 하락은 사실이 아니다**(DBSCAN도 같은
   값). 조각난 거점에도 각각 원(코어 500m·P90)이 씌워져 합집합이 유지되기
   때문이다. 코호트 평균으로 봐도 판정 성능은 동급이다(커버리지 90.9% 동일,
   반복거점 누락 1.6% 동일). **심사위원이 실험실 탭에서 같은 행을 열면 바로
   드러나는 오류였으므로 세 문서에서 모두 철회**하고, 결론(현행 유지)은 유지하되
   근거를 **"성능 우위" → "`min_samples` 무근거 + 경계 사례 설명 불가"**로
   교체했다. → `06_결정대기_팀조사_삼분류.md`, `근거자료/생활권판정방법론_리포트.html`
2. **중복 파일 6건 제거** — `reports/`의 4건(마스터 도시에·FEEDBACK2·QNA_PREP 2건)과
