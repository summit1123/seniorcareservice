## 3. 최근 논의 이슈 정리 (7/27~28)

### 3-1. DBSCAN vs HDBSCAN 논쟁 — 최종 결론

팀 주장 "HDBSCAN이면 eps 없이 되는데 왜 DBSCAN이냐"에 대한 정리:

1. **파라미터는 사라지지 않고 이동** — HDBSCAN도 무리(min_cluster_size)·이웃
   (min_samples)을 사람이 정함. "왜 260m냐"(문헌 대역·약관 서술 가능)가 "왜 무리
   3이냐"(설명 곤란)로 바뀔 뿐.
2. **"알아서"의 실체는 소표본 추정** — 사람당 점 수십 개에서 밀도를 추정 →
   실험실 실측: 거점 8개로 파편화, 커버리지 90%→**71.9%**. (메커니즘: 거점 하나
   안의 우연한 주차 몰림을 "서로 다른 군집"으로 오독 — 소표본에선 우연과 구조를
   구분할 정보가 없음)
3. **우리는 잣대에 필요한 정보(지역)를 주소로 이미 앎** — 아는 정보를 쓰는 것
   (지역 어댑터)이 부족한 데이터로 추정하는 것보다 정확.
4. **사람 단위 군집이라 HDBSCAN의 존재 이유(한 판 혼합 밀도)가 우리에겐 드묾.**
5. **'서로 다른 3일' 규칙은 HDBSCAN에 없어 어차피 별도 구현 필요.**
6. eps는 부담이 아니라 카드 — "다른 시장엔 eps만 재조정" = 국제 이식성 스토리.

**최종 포지션**: 운영 = 지역별 eps DBSCAN 변형(설명 가능·소표본 강함) / HDBSCAN =
좋은 알고리즘이지만 지금 데이터 규모·설명 요건에선 비용>이득 → 실험실 비교 중 +
실데이터 파일럿 승격 후보. **"쓰냐 마냐"가 아니라 "언제 쓰냐"의 문제.**

### 3-2. "도심/농촌 구분(지역 어댑터)을 버리자" — 답

버리면 남는 선택지는 둘뿐: ① 전국 eps 하나 = 원논문(p.229)이 자인한 실패 상태로
복귀(농촌 거점 파편화 or 도심 병합) ② HDBSCAN = 위 3-1의 실측 실패. 지역 티어는
개인화의 반대가 아니라 **개인화의 입력값**(주소=개인 속성)이며, 그 위의 존
개수·위치·원 크기(P90)·밖 비중은 전부 개인 실측. 게다가 지역 차등은 심사위원이
직접 제안한 항목(B-2 최강 카드)이라 버리면 전략적으로도 손해.

### 3-3. DEGURBA 밖 주행 가중 스코어링(팀 제안 수식) — 평가

수식 자체(율 기반 w, 분모 직교, 티어 풀링, 고령 필터)는 방법론적으로 우수. 단
그대로 넣으면 안 되는 3가지: ① **행동 축 부재** — 거리·지역만으로 케어를 자름
② **절대 임계(θ) = 위치 벌점** — A-1 방어선("교란 요인은 판정 불진입")과 지역
공정성(케어 60/60) 붕괴 ③ "지나간 지역"은 경로 데이터 필요(우리 비수집).

**살리는 법**: r을 절대 티어링이 아니라 **케어 이동 축의 정교화(직전 2개월 평균
대비 Δr)**로 넣고, 티어는 경로 대신 도착지, 조인은 시군구 대신 우리 3환경 매핑
(DEGURBA 도시/중간/농촌 ↔ 도심/교외/광역 1:1). DEGURBA(UN 표준, 인구밀도
1,500/300 임계)는 운영 시 지역 어댑터의 분류 기준으로 채택 — 팀 조사가 이 빈칸을
정확히 채움.

### 3-4. 페르소나 유형 근거·비율 방어

- **유형 근거**: 6유형 = 문헌이 보고한 3축(이동범위 축소·만성 위험행동·패턴
  변화)의 조합. 상세 표 → `페르소나_6유형_근거표.md`
- **"유형이 임의면 산식까지 문제" 사슬 절단**: 산식은 페르소나에서 도출된 적이
  없음(독립 근거 스택). 페르소나 = 산식을 시험하는 **테스트 케이스** — 실패해야
  할 케이스(이사형 30건, 오탐 0)까지 포함. 채점 엔진은 유형 라벨을 모름(블라인드).
- **10명 균등 배분 방어**: 판정은 개인 단위라 비율 무관("화재가 드물다고 대피
  훈련이 무효가 아니다"). 유형별 평균 비교(19.6→7.9%)도 유형 내 평균이라 구성
  무관. 비율이 영향 주는 건 **포트폴리오 합계 하나뿐** → "구성비별 재계산"으로
  방어(요청 시 개발 반나절).

### 3-5. 기준선·임계 근거 완성 (동현 파트)

- **왜 3일**: Isaacman 2011 정면 일치(60일 관찰·5%=3일·call-days 계수) + 푸아송
  오류표(2일=오인 26%/3일=8%/4일=진짜 거점 절반 누락) + 국내 빈도 앵커(건보 월
  3.75일, 경로당 주 2.9회) + 우리 데이터 실측(진짜 거점 탈락 0).
- **왜 2개월**: 운전 빈도 역산(주 3~5회 → 2개월 26~43회, 소비자원 2024) + 선례
  스펙트럼(UMTRI 2주 → DRIVES 1개월 → **Isaacman 60일** → 업계 6개월/Progressive
  공식) + Lally는 보조 한 문장으로 강등.
- **왜 260/520/1,100**: 도심 값은 장소인식 문헌 대역(200~300m) + ×2 축척 규칙 +
  실험실 민감도/채점표 + 파일럿 k-거리 재도출 로드맵.
- 상세: `EVIDENCE_기준선_방문임계_노트.md`(원문 인용·링크) / 팀 공유용
  `기준선_가중치_근거정리.pdf`(용어 순화판, 링크 20개 클릭 가능).
